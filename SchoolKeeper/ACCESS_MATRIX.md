# Матрица доступа SchoolKeeper

Проставьте крестики (✓) в ячейках, где роль должна иметь доступ к функции.

## Роли
- **Admin** - Администратор
- **Security** - Служба безопасности
- **Teacher** - Учитель
- **Parent** - Родитель
- **Student** - Студент

## Примечания

1. **Фильтрация по школе**: Не-администраторы видят только данные своей школы
2. **Доступ к собственным данным**: Некоторые роли могут видеть только свои собственные инциденты/данные
3. **Специальные ограничения**: 
   - Учителя могут обновлять только свои инциденты
   - Студенты и учителя могут видеть только свои инциденты
   - Security может видеть пользователей только своей школы
